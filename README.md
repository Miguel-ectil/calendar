# Calendario

### Funcionalidades
- Este repositório contém um projeto de visualização de calendário interativo desenvolvido com HTML, CSS e JavaScript. O calendário permite a visualização de dias, semanas e meses, proporcionando uma maneira intuitiva de gerenciar e visualizar datas importantes.

## Tecnologias Utilizadas

  - JavaScript: Linguagem de programação para construção da interface de usuários.
  - HTML: Linguagem de marcação de texto.
  - CSS: Linguagem de estilização de texto.
  
## Instruções de Uso

1. Clone o repositório.
2. Abra o arquivo index.html em qualquer navegador de sua preferência.
3. Utilize a calculadora para realizar suas operações matemáticas!
